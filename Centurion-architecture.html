核心引擎 Centurion.Core —— 编排层 + 管道算子 + 可插拔策略

PipelineExecutor（DAG 执行器）

  • 节点 = 算子，边 = 数据依赖；按拓扑序执行，支持并行分支
  • 条件节点（when）与降级：VocalSeparation ↔ Diarization 可并行
  • 每节点超时 / 重试 / 取消；步骤计时 → StepTimings；全程可取消
  • 非致命错误记 warn 并继续；单节点失败不拖垮整个任务

PipelineOperatorFactory

  • 按 WorkflowConfig 预解析策略并组装算子
  • Transcribe / SentenceSplit / Diarization / Alignment 四类算子装配
  • Diarization/Alignment 按开关返回 null（不组装该阶段）
  • 注入模型注册表（ModelRegistry）校验模型名

AddCenturionCore（DI 集中注册）

  • MetadataJsonLoader 启动加载 Tools/Models 注册表
  • 基础设施、5 个策略工厂、全部管道算子
  • 自更新服务 IUpdateService → GitHubUpdateService
  • CLI / Server 入口均只调用这一个扩展方法

SubtitleWorkflowContext —— 全管道唯一传递对象（引用传递，可序列化支持检查点）

WorkflowConfig（不可变配置）

  • 输入/输出路径、语言、设备（auto/cpu/cuda…）
  • 转录引擎 + 模型、分句策略、对齐开关
  • 说话人分割后端、人声分离开关、OCR 后端
  • 翻译 / dub（TTS、混音、响度）全量参数

WorkflowState（可变状态，字段分层契约）

  • 正式字段（随 IR 持久化）：音频路径链、各阶段句子列表、阶段标志、Styles、Dub 数据
  • 运行时字段 [JsonIgnore]：StepTimings / CorrectionMetadata / ProviderUsages（用量聚合，命令收尾输出）
  • Extensions 临时槽：单算子私有/边缘数据（SNR 诊断、轨道/拼写检查），不写入 IR
主流程算子链（DAG 编排，动态组装）
SubtitleTrackChecker 轨道检查→ FFmpegConvert 转换→ AudioPreprocess 重采样/高通/响度/降噪→ VocalSeparation 人声分离（可选）→ Transcribe 转录→ Diarization 说话人分割（可选）→ SentenceSplit 分句→ TextCleaning 清洗→ Alignment 词级强制对齐（可选）→ QualityReport 质量报告→ 保存 IR 中间文件
OCR 分支→ VideoSubFinder 提取字幕帧（sourceforge 自动下载）→ OcrExtract 识别（RapidOCR 本地 ONNX / GLM-OCR 云 / Ollama / llama.cpp）→ 去重合并 → 时间轴句→ 合并进 IR
其他命令链：dub：SpeakerProfiling → TtsSynthesis（Qwen3-TTS）→ TimeAlignment → AudioMix → QualityReport → .dub.wav； correct：ScriptLoader → SubtitleTextCorrector → FFmpegConvert → AudioPreprocess →（VocalSep）→ Alignment → OverlapResolution → CorrectionReport → QualityReport； convert：ConvertParseOperator（SubtitlesParserV2）；from-script：ScriptLoader → ScriptTimelineMapper； build：加载 IR → SubtitleFormatRenderer / AssSubBuilder 渲染 ASS/SRT/TXT（不走 Executor）；validate / migrate：IR Schema 前置校验与升级。

数据产物 单一富中间文件串起命令链

IR 中间文件 · *.centurion.json（schema 1.0）

  • 根契约 CenturionDocument：schemaVersion + generator（工具/命令/时间）+ provenance（每步骤 operator/模型/参数哈希）+ config + state
  • 生成：asr / ocr / from-script / convert；链式加工：correct → translate → dub
  • System.Text.Json 源生成器序列化（CenturionJsonContext，无反射）
  • 统一读写：ICenturionDocumentStore；validate 前置校验；migrate 升级旧格式（legacy → 1.0）
  • JSON Schema：schemas/centurion-v1.json（JsonSchemaExporter 生成）

输出产物

  • build → ASS（默认，样式/双语/卡拉OK \K/说话人标签）· SRT · TXT
  • dub → 译制 .dub.wav（时间对齐 + ducking 混音 + LUFS 响度）
  • 每命令写入 .quality.json（覆盖率/漂移/CPS/警告）
  • spellcheck → .spellcheck.json
